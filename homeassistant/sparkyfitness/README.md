# SparkyFitness Home Assistant add-on

Run the SparkyFitness server (web UI + API + PostgreSQL) as a Home Assistant
add-on. Built for HAOS, including Raspberry Pi 5.

Installation: **Settings → Add-ons → Add-on Store → ⋮ → Repositories** → add
`https://github.com/CodeWithCJ/SparkyFitness` → install **SparkyFitness**.

Full steps: [DOCS.md](DOCS.md)
