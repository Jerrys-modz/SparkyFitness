# Home Assistant add-ons

This directory is a Home Assistant add-on repository. Add
`https://github.com/CodeWithCJ/SparkyFitness` under **Settings → Add-ons →
Add-on Store → ⋮ → Repositories**, then install **SparkyFitness**.

The add-on runs the published `codewithcj/sparkyfitness` and
`codewithcj/sparkyfitness_server` images plus a bundled PostgreSQL in a
single Supervisor container — the same stack as Docker Compose, without a
second machine.

See [sparkyfitness/DOCS.md](sparkyfitness/DOCS.md) and the
[install guide](https://codewithcj.github.io/SparkyFitness/install/home-assistant).
