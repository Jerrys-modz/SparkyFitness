# Home Assistant (HAOS)

Run SparkyFitness as a **Home Assistant add-on** on the same device as Home
Assistant OS (for example a Raspberry Pi 5). This is a Supervisor add-on,
not a HACS integration — the same pattern Mealie and Donetick use.

The add-on bundles PostgreSQL, the API server, and the web UI in one
container using the published Docker images. You do not need a second Pi
or the Portainer workaround.

## Install

1. In Home Assistant go to **Settings → Add-ons → Add-on Store**.
2. Three-dot menu → **Repositories** → add:

   `https://github.com/CodeWithCJ/SparkyFitness`

   The first fetch clones this git repository and can take a minute.
3. Install **SparkyFitness**. The first build pulls the official images
   (aarch64 and amd64); it does not compile the app on the Pi.
4. Set **Public URL** to the URL you will actually use, including the
   port (default host port is `3004`):

   `http://homeassistant.local:3004`

   or your LAN IP, e.g. `http://192.168.1.50:3004`.
5. Set **Timezone**, start the add-on, and open the web UI. First boot
   initializes the database and may take a couple of minutes.
6. Create your account. Optionally put that address in **Admin email**
   and turn on **Disable signup**.

Put the same Public URL into the SparkyFitness iOS/Android app. Do **not**
use a Home Assistant ingress URL (`/api/hassio_ingress/…`); the web app
calls `/api` on its own origin, so the mobile app needs `host:port`.

The add-on **Configuration** tab covers timezone, signup, Garmin (toggle
**Enable Garmin** then link the account in SparkyFitness), SMTP, and a
free-form list for any other environment variable (OIDC, proxies, …).
Database secrets are generated on first start and stored in the add-on
data volume. Home Assistant backups include that volume — keep it.

Full add-on options, updates, and why Ingress is not used:
[add-on DOCS.md](https://github.com/CodeWithCJ/SparkyFitness/blob/main/homeassistant/sparkyfitness/DOCS.md).

## Portainer instead

If you already run the Portainer add-on, you can deploy the Compose stack
with the [Portainer guide](/install/portainer) instead of this add-on.
