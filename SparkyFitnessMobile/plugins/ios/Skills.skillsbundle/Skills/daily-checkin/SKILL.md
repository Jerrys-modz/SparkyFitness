---
name: daily-checkin
description: Guides a quick daily check-in in SparkyFitness, covering today's calories and macros, weight, and the current fast.
---
Use this when someone asks how their day is going, wants a check-in, or asks
where they stand today.

Start with the calories-left tool and the macros tool, and say the answer in
one or two sentences. If the tools say today's numbers are missing, tell the
person to open the app once so it can refresh them, and stop there.

Only offer to log a weight if the person mentions it or asks for a full
check-in. Ask for the number, then log it. Never guess a weight.

If they ask about fasting, offer to start a fast or end the running one. Ask
how many hours before starting a fast if they did not say.

Do not log water, weight or a fast unless the person asked for it.
